# 视频观看时间管家（Edge 扩展）

支持网站：优酷（youku.com）、爱奇艺（iqiyi.com）、腾讯视频（v.qq.com）。三个网站共用同一套计时，休息/锁定时三个网站的页面都会被遮罩。

## 安装
1. Edge 打开 `edge://extensions`，打开左侧「开发人员模式」。
2. 点「加载解压缩的扩展」，选择本文件夹 `youku-timer`。
3. 点工具栏上的扩展图标，可以修改设置并查看当前状态。

## 规则
- 只在视频真正播放时计时（多个标签页同时播放也只算一份）。
- **何时休息**：尽量在一集的结尾或开头停，不在半集打断（默认每次 20 分钟，最多允许超时 10 分钟）。
  - 一集播完时：按“下一集和这集一样长”估算，比较“现在停（少看）”和“看完下一集再停（多看）”，选偏差小的；
  - 下一集开始时：用它的真实时长再判断一次，会超时太多就立即休息；
  - 还没看到一半时不会提前停；
  - 播放中途时间到（例如电影）：剩余不超过允许超时就等这集播完，否则立即停。
- **休息时长**按实际观看时长等比例调整：实际观看 ÷ 每次可观看 × 标准休息（默认 5 分钟），最少 1 分钟，最多 2 倍。
- 休息期间所有支持网站的页面（包括新打开的）都会被半透明遮罩（不透明度 70%）盖住并暂停，键盘鼠标无效，显示倒计时。
- 休息期间会请求系统的“屏幕唤醒锁”，避免电脑因为没有操作而息屏；页面在后台或系统策略不允许时可能会降级。
- 倒计时结束后不会自动播放：
  - 原页面（休息前正在看的页面）遮罩保留，按键盘任意键或鼠标任意键即取消遮罩并继续播放；默认同时自动进入全屏，可在设置中关闭；
  - 其他视频网站页面的遮罩自动取消。
- **每天上限**（默认 60 分钟，最多允许超时 20 分钟）用同样的集边界规则结束；结束后当天所有支持网站的页面都被遮罩，提示今天已经看了多长时间，次日零点自动解除。
- 设置弹窗中的「全部重置」会清空本次和今日计时，并解除休息/锁定（家长用）。

## 已知限制
- 自动全屏会在用户按任意键或点击继续时立即请求，但个别播放器、iframe 或网站权限策略可能拒绝网页全屏，此时仍会正常播放。
- 短于 3 分钟的视频按广告处理，不参与集边界判断（见 `content.js` 里的 `MIN_MAIN_DURATION`）。
- 换集靠“页面路径 + 视频时长”识别；如果网站连播时两者都不变，只能靠视频播完事件判断。
